XUANJI // 小六壬

小六壬

MA QIAN KE · INTRO

是什么

小六壬又称「马前课」「掐指一算」，相传为三国诸葛亮行军打仗时于马上所创，故名马前课。它是民间最便捷的占法——不用卦、不用签，一只手掌六个位置，以月、日、时三数依次掐算，最后落定一宫即断吉凶。

原理

六宫依次为：大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡。起法为「正月起大安」——从大安开始数到所占之月，该宫即月落宫；再从月落宫起初一，数到所占之日；再从日落宫起子时，数到所占之时辰。最终落宫定断。

  • 大安（木·吉）：身未动，事安稳，贵人扶。
  • 留连（水·凶）：事拖延，人未归，反复纠缠。
  • 速喜（火·吉）：喜事至，有音信，立等可成。
  • 赤口（金·凶）：口舌起，是非多，宜慎言。
  • 小吉（木·吉）：和合吉，婚恋宜，将门有喜。
  • 空亡（土·凶）：事落空，信音稀，徒劳无功。

怎么用

  • 心中默念所问（一事一占）。
  • 输入农历月、日与时辰，起课落宫。
  • 以落宫总断，再参看所问事项的分断。

术语速查

落宫 — 时辰数最终停留之宫，断吉凶的依据。
时辰 — 子丑寅卯……十二时辰，每时辰两小时，23:00 起为子时。
留连 / 空亡 — 六宫中最需要警惕的两宫，非"大凶"而是"不利急成"。
