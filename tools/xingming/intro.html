姓名九宫

NAME GRID · INTRO

是什么

姓名九宫是传统姓名学与现代流行的「五格剖象法」的结合玩法：以姓名每个字的康熙字典笔画为基础，推算天格、人格、地格、外格、总格五格数理，并配八十一数理吉凶；再以总笔画归入洛书九宫，看姓名的九星落宫。五格剖象法由日本人熊崎健翁在 20 世纪初整理推广，东亚流传极广。

原理

  • 天格：姓氏之数（单姓 +1，双姓相加）——先天、祖荫。
  • 人格：姓末字 + 名首字——主格，性格与命运的核心。
  • 地格：名字之数（单名 +1）——前运、早年。
  • 外格：总格 − 人格 + 1——人际、外围。
  • 总格：全名总笔画——后运、晚景。
  • 三才：天、人、地格的尾数五行（1,2 木 / 3,4 火 / 5,6 土 / 7,8 金 / 9,0 水）相生相克。
  • 九宫：总笔画各位数字反复相加至 1-9，对应洛书九星。

怎么用

  • 输入姓氏与名字（支持单双姓、单双名）。
  • 生僻字按提示手动填入康熙笔画。
  • 看五格数理吉凶 + 三才关系 + 九宫落星，综合读解。

术语速查

康熙笔画 — 按繁体并按康熙字典部首口径计（氵=水 4、艹=艸 6、右阝=邑 7、左阝=阜 8、王旁=玉 5）。
人格 — 五格之首，断姓名吉凶以人格为主、总格为辅。
洛书九星 — 一白到九紫九星，各主性情与吉凶方位。
