# 添加新工具 —— 扩展接口文档

本站为"后续添加"而设计。加一个新占卜工具只需三步，**不需要改动任何现有文件**（除了注册表加一行）。

## 三步接入

### 第 1 步：复制模板

把 `tools/_template/` 整个目录复制为 `tools/你的工具id/`（id 用小写英文，如 `zhouyi`、`qimen`、`lifu`……）。

目录内四件套：

| 文件 | 职责 |
|---|---|
| `index.html` | 使用页（交互界面） |
| `intro.html` | 介绍页（原理、术语、使用说明） |
| `logic.js` | 算法与渲染 |
| `data.js` | 纯数据（签文/牌义/字典/配置……） |

**数据与逻辑分离**是本站的扩展原则：想换一套签文、一批牌义、一个字典？只动 `data.js`，算法一行不改。

### 第 2 步：注册工具

打开 `assets/js/registry.js`，在数组里追加一条：

```js
{
  id: 'zhouyi',              // 与目录名一致
  icon: '☰',                 // 首页卡片图标（一个字符）
  name: '周易',
  en: 'I CHING',
  tag: '蓍草 · 卦爻辞',       // 一句话分类标签
  desc: '六十四卦卦爻辞断占，回到《周易》原文。',
  use: 'tools/zhouyi/index.html',
  intro: 'tools/zhouyi/intro.html'
}
```

保存刷新，首页卡片、全站顶部导航、使用/介绍页签**全部自动出现**。

### 第 3 步：填内容

- 两个 html 的 `<body>` 标签上写好 `data-tool="zhouyi"` 与 `data-page="use"` / `"intro"`；
- `logic.js` 里写交互逻辑；
- `data.js` 挂 `window.XXX_DATA`，logic.js 里取用。

## 共享能力（core.js 免费提供）

在 `logic.js` 里直接用全局 `CY` 对象：

| 接口 | 说明 |
|---|---|
| `CY.randInt(n)` | 加密无偏随机整数 [0, n) ——所有随机工具统一用它 |
| `CY.pick(arr)` | 随机取一项 |
| `CY.coin()` | 掷一枚硬币（1=阳/0=阴） |
| `CY.TRIS` / `CY.TRIS_KEYS` | 八卦数据（符号、笔画线、五行） |
| `CY.guaInfo(上,下)` / `CY.linesFrom` / `CY.guaFromLines` | 64 卦查询与转换 |
| `CY.huLines` / `CY.bianLines` | 互卦 / 变卦计算 |
| `CY.yaoName(i, yang)` | 爻名（初九、六二、上六……） |
| `CY.svgGua(lines, moving)` | 卦象 SVG 渲染（动爻自动琥珀高亮） |
| `CY.tiYong(体, 用)` | 五行体用生克判断 |
| `CY.esc(s)` | HTML 转义（输出用户输入前必须转义） |
| `CY.luckClass(luck)` | 吉凶徽章配色 |

## 设计规范（保持全站一致）

- 面板用 `<section class="panel">`，重点结论加 `hl`；
- 徽章：吉 `b-ji` / 凶 `b-xiong` / 中 `b-zhong`，主色 `b-cy`、品红 `b-mg`；
- 按钮主操作 `btn primary`，次要 `btn`，危险/重置 `btn mag`；
- 结果区统一放在 `<div id="result">`；
- 每个占卜结果都要出现一次"理性提示"（介绍页结尾固定有）。

## 数据驱动的进阶玩法

以塔罗为例：小牌牌义由 `SUITS × RANKS` 结构化生成，`MINOR_EXTRA` 可逐张覆盖——
这就是"先结构生成、后精修覆盖"的模式，新工具的数据层建议照此设计。

签文、数理表同理：`qian-data.js` 整体换成观音灵签 100 签，`chouqian.js` 无需任何改动。
