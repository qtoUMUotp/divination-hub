# 部署指南 —— 把「玄机」发布到 GitHub Pages

> 面向零基础小白，全程不需要命令行。已有 GitHub 账号即可，全程约 10 分钟。
> 上线后你会得到一个公网地址，任何人在浏览器输入即可访问。

## 第一步：新建仓库

1. 打开 [github.com](https://github.com) 并登录。
2. 点右上角 **`+` → New repository**（新建仓库）。
3. 填写：
   - **Repository name**（仓库名）：建议 `divination-hub`（也可以用别的，但会影响最终网址）
   - **Public**（公开）——必须选公开，Pages 免费版只支持公开仓库
   - 其余全部不用动
4. 点 **Create repository**。

## 第二步：上传文件

1. 创建完成后的页面里，点 **uploading an existing file** 链接
   （中文界面是"**上传现有文件**"）。
2. 把 `divination-hub` 文件夹里**所有内容**（注意：是文件夹里面的内容，不是文件夹本身）拖进上传区。
   - 如果文件多，可以分批拖，但**目录结构必须保持原样**（index.html 在最外层，assets、tools、docs 是子文件夹）。
3. 下方 Commit message 随便写（如 `init`），点 **Commit changes**。

## 第三步：开启 GitHub Pages

1. 进入你的仓库页面，点顶部 **Settings**（设置）。
2. 左侧菜单点 **Pages**。
3. **Build and deployment** 区域：
   - Source 选 **Deploy from a branch**
   - Branch 选 `main`、文件夹选 `/ (root)`
   - 点 **Save**
4. 等待 1~3 分钟，刷新该页面，顶部会出现绿字提示：
   `Your site is live at https://你的用户名.github.io/divination-hub/`

这串地址就是你的网站，可以发给任何人。

## 第四步（以后）：更新网站

改了本地文件后，在仓库页面对应文件旁点 ✏️ 编辑，或再次用上传功能：
上传同名文件时会提示"替换/commit"，确认即可。GitHub Pages 会自动重新部署。

## 常见问题

| 问题 | 处理 |
|---|---|
| 网址打开是 404 | 等 3 分钟再刷新；确认 Pages 的 Branch 选的是 `main / (root)` |
| 样式全丢/白板 | 上传时目录结构被打平了。index.html 必须在仓库根目录，`assets/`、`tools/` 是它的子文件夹 |
| 想换仓库名 | Settings → General → Rename。网址会跟着变 |
| 想要自定义域名 | Settings → Pages → Custom domain，填入你购买的域名 |
| 改了文件没生效 | Pages 部署要 1~3 分钟；浏览器可能缓存，Ctrl+F5 强制刷新 |

## 进阶（可选）：用 git 命令行管理

等熟悉后，在本地安装 [Git](https://git-scm.com/downloads)，然后：

```bash
cd divination-hub
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin https://github.com/你的用户名/divination-hub.git
git push -u origin main
```

之后每次更新只需 `git add . && git commit -m "更新说明" && git push`。
