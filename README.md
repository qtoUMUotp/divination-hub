# 玄机 · Cyber Oracle

赛博极简风格的**纯前端占卜工具合集**。零依赖、零构建、无后端——任何静态托管（GitHub Pages / Vercel / 本地双击）。
整体出于个人学习、使用需求制作，基本由AI生成。（本来想叫赛博奶嘴但是感觉好像有点不礼貌……但我真的用的很开心）

## 目录结构

```
divination-hub/
├── index.html              # 首页（卡片由注册表自动生成）
├── assets/
│   ├── css/style.css       # 全站设计系统（改一处，全站变）
│   └── js/
│       ├── registry.js     # ★ 工具注册表——加新工具的唯一入口
```
